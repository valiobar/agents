# Auth Service Data Flow

## Registration Flow

```mermaid
sequenceDiagram
    participant Client
    participant Gateway
    participant Auth
    participant Mongo

    Client->>Gateway: POST /auth/register
    Gateway->>Auth: proxy request
    Auth->>Mongo: find user by email
    Auth->>Auth: hash password
    Auth->>Mongo: insert user
    Auth->>Auth: create access + refresh tokens
    Auth-->>Gateway: token pair
    Gateway-->>Client: token pair
```

## Google OAuth Flow

```mermaid
sequenceDiagram
    participant Client
    participant Gateway
    participant Auth
    participant Google
    participant Mongo

    Client->>Gateway: POST /auth/oauth/google { id_token }
    Gateway->>Auth: proxy request
    Auth->>Google: verify ID token
    Google-->>Auth: claims
    Auth->>Mongo: find by google_id or email
    Auth->>Mongo: create or link user if needed
    Auth->>Auth: create access + refresh tokens
    Auth-->>Gateway: token pair
    Gateway-->>Client: token pair
```

## Refresh Flow

```mermaid
sequenceDiagram
    participant Client
    participant Gateway
    participant Auth

    Client->>Gateway: POST /auth/refresh { refresh_token }
    Gateway->>Auth: proxy request
    Auth->>Auth: decode token
    Auth->>Auth: verify type == refresh
    Auth->>Auth: create new access + refresh tokens
    Auth-->>Gateway: token pair
    Gateway-->>Client: token pair
```

## Profile Flow

```mermaid
sequenceDiagram
    participant Client
    participant Gateway
    participant Auth
    participant Mongo

    Client->>Gateway: GET /auth/me + access token
    Gateway->>Auth: proxy request
    Auth->>Auth: decode access token
    Auth->>Mongo: find user by id
    Auth-->>Gateway: user profile
    Gateway-->>Client: user profile
```

## Write Paths

| Data | Write Path |
|------|------------|
| New credentials user | Auth service -> User repository -> MongoDB |
| New Google user | Auth service -> Google verification -> User repository -> MongoDB |
| Linked Google account | Auth service -> User repository -> MongoDB |
| Tokens | Generated by Auth service; not persisted |
